# RYM Solmet

Antes de modificar la interfaz, lee completos `PRODUCT.md`, `DESIGN.md` y `.agents/skills/rym-solmet/SKILL.md`.

- `PRODUCT.md` contiene los hechos del emprendimiento.
- `DESIGN.md` contiene las reglas visuales.
- `src/data/projects.ts` es la única fuente para títulos, orden, imágenes y textos alternativos.
- No inventes clientes, ubicaciones, fechas, métricas ni capacidades.
- No sustituyas fotografías reales por stock, ilustraciones o efectos que oculten el material.
- Verifica con `npm run check` y `npm run build`; para cambios visuales, revisa también los tamaños indicados en la skill del proyecto.
